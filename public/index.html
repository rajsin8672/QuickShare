How QuickShare Works

Three easy steps to move files between any desktop, phone, or colleague.

1

Upload Content

Drop your documents, photos, or enter a text message. Choose your desired expiration period from 30 minutes to 7 days.

2

Get Your Code

QuickShare generates an unambiguous 6-character code (or QR code). Only those with the code can access the files.

3

Download & Done

The receiver enters the code to preview files or download them individually or as a single ZIP archive.

Supported File Formats

Up to 25MB per file, 50MB per share, and up to 10 files simultaneously.

PDF Documents JPG & PNG WEBP TXT Plaintext Word DOC / DOCX

Engineered for Security & Speed

Enterprise-grade protection with consumer-grade simplicity.

Password Protection

Set an optional password for sensitive transfers. Files remain strictly locked until the recipient authenticates.

Automatic Expiration

Files purge automatically after your configured expiry window (30m, 1h, 6h, 24h, 7d). No residual data left behind.

Download Limits

Enforce a maximum number of successful downloads. Once reached, the share automatically self-terminates.

Private Storage

Files are stored in private Supabase Storage buckets, guarded by backend authorization and temporary signed streams.

In-Browser Previews

Recipients can safely preview PDFs, image galleries, and plain text notes without downloading first.

Owner Deletion Tokens

Senders receive a cryptographic owner token to delete shares immediately at any time before expiration.
